# 전담시간표 데스크톱 앱

초등학교 전담·특별실 시간표를 설정하고, 자동으로 여러 배치안을 만들어 비교할 수 있는 Windows 데스크톱 프로그램입니다.

## 실행

```bash
npm install
npm start
```

## 실행 파일 만들기

설치형과 바로 실행형을 함께 만듭니다.

```bash
npm run dist
```

바로 실행형만 만들려면:

```bash
npm run dist:portable
```

완성 파일은 `dist` 폴더에 생성됩니다.

## 사용 흐름

1. 기본 설정에서 학급 수와 특별실을 입력합니다.
2. 전담 배정에서 전담별 과목, 시수, 수업형태, 학급을 선택합니다.
3. 제외시간에서 공통, 전담별, 특별실별 제외시간을 선택합니다.
4. 특별실 배정에서 전담과 무관한 특별실 사용을 선택합니다.
5. 시간표 작성을 누르고 추천안을 확인합니다.
6. 필요하면 수업칸을 잠금하고 다시 작성하거나, 엑셀/출력용 보기로 저장합니다.

## 현재 포함된 기능

- 학교명/학년도별 설정 저장, 불러오기, 이름변경, 삭제
- 샘플 설정 불러오기
- 초기화 버튼으로 배포용 깨끗한 상태로 되돌리기
- 전담별 여러 과목 배정
- 공통/전담/특별실 제외시간
- 전담시간표와 특별실시간표 자동 작성
- 자동 추천안, 재시도, 미배치 표시
- 수업칸 잠금과 드래그 이동
- 일반모드/다크모드
- 엑셀 저장, 출력용 보기, 바로 출력

## 빌드가 막힐 때

PowerShell에서 `npm` 실행 보안 오류가 나면 다음처럼 실행합니다.

```bash
npm.cmd run dist:portable
```

`spawn EPERM app-builder.exe` 오류가 나면 OneDrive나 Windows 보안이 빌드 도구 실행을 막은 상태입니다. 프로젝트 폴더를 OneDrive 밖의 일반 폴더로 복사한 뒤 다시 실행하면 풀리는 경우가 많습니다.

예시: `C:\Projects\전담시간표프로그램`
